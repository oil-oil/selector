## 项目理解要点

Selector 是一个浏览器书签工具，核心功能：
- 书签注入方式（无需 Chrome 插件），跨浏览器兼容
- 可视化选择页面元素，支持单击/Shift多选/拖拽框选/DOM 导航
- 每个元素可附加指令，导出结构化 prompt
- 两种导出方式：剪贴板复制 / 本地服务器直发 Claude Code（localhost:7734）
- 纯客户端，无数据外传
- 服务器仅用 Node.js 内置模块，无外部依赖
