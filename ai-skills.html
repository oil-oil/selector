AI Skills / 2025

我每天在用的
五个 AI Skill

分享它们各自是怎么跑的，
以及我实际用来干什么

codex

编程任务直接
委托给 Codex CLI

调用 Codex CLI 在本地终端执行编码任务。 你用自然语言描述需求，它生成代码、执行命令， 结果直接落到文件里。

  • 底层走 Codex CLI，在本地终端执行
  • 支持多文件修改、跑测试、执行 shell 命令
  • 需求写得越具体，生成质量越高
glm-fe

前端任务的
专属执行 Agent

底层由 GLM（opencode）驱动，专门处理前端开发工作。 新建组件、修改页面、加动画、调样式，都在这里完成。

  • GLM opencode 模型执行，熟悉项目结构
  • 覆盖组件创建、样式调整、动画效果
  • 直接在项目里改，结果可以立刻跑
lark-dev-diary

扫 git log，
生成飞书日报

读取当天的 git commit 记录，逐条引导你补充 背景和原因，最后调用 lark-doc 接口写进飞书文档。

  • 自动执行 git log 拿当日提交列表
  • 交互式逐条补充上下文
  • 调用 lark-doc API 写入飞书，返回文档链接
git-ship

说一声 ship，
跑完整个发布流程

基于最新 main 切新分支，依次执行 commit、push、 创建 PR、轮询 CI 状态，全绿后 squash merge，最后切回 main。

  • 从最新 main 自动切分支，避免遗漏更新
  • 轮询 CI 状态，只在全绿时才执行 merge
  • 只在你明确说「ship」时触发，不会误操作
frontend-slides

生成零依赖的
单文件 HTML 幻灯片

在 Claude Code 里完成整个流程：引导选风格、整理内容， 输出一个内嵌 CSS/JS 的 HTML 文件。你现在看的就是它生成的。

  • 单文件，无需 npm 或任何构建工具
  • 内嵌 scroll-snap 导航和 IntersectionObserver 动画
  • 支持在浏览器里直接点击编辑文字

小结

五个 Skill，
各管各的一块

codex 写代码、glm-fe 做前端、 lark-dev-diary 写日报、git-ship 发版、 frontend-slides 做幻灯片。
日常用得挺顺的，分享出来。
